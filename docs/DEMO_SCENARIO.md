# F1 입문자 튜토리얼 AI — 데모 시나리오 스크립트

발표/데모 때 따라 하는 대본. 기능 8종을 2~3분에 자연스럽게 보여준다.
(용어집·말투는 이미 구현됨. 이 문서는 "무엇을 어떤 순서로 시연하나"의 대본.)

---

## 준비 (전제)
- 씬: **SessionSpace** (2025 일본 GP · 스즈카 · 트랙 에셋 있음)
- 서버 2개 켜짐: 데이터 서버(:8000), AI 서버(:8001, 워밍업 완료)
- 입력: 마이크(권장) 또는 텍스트 테스터 (마이크 불가 시 텍스트로 동일 진행)
- 리플레이가 로드돼 차들이 달리는 상태에서 시작

---

## 시연 순서 (발화 → 기대 동작 → 화면)

| # | 발화(말/입력) | 기대 AI 동작 | 기대 화면 | 검증 기능 |
|---|---|---|---|---|
| 1 | "DRS가 뭐야?" | 용어를 2~3문장으로 설명 | (명령 없음) 자막·음성 | explain_concept |
| 2 | "1번 선수 누구야?" | 선수 정보 + 그 차 강조 | 해당 차에 마커 | get_driver_info + highlightDriver |
| 3 | "지금 몇 등이야?" | 현재 시점 순위(상위) | 자막·음성 | get_race_status (at_time) |
| 4 | "쟤 왜 저래?" / "왜 피트인했어?" | 타이어·피트 근거로 이유 | 자막·음성 | explain_why |
| 5 | "천천히 다시 보여줘" | 재생 속도 낮춤 | 리플레이 슬로모 | controlReplay(speed) |
| 6 | "첫 피트스톱 보여줘" | 그 장면으로 점프 | 리플레이 시크 이동 | jump_to_event(seek) |
| 7 | "2024 스즈카로 바꿔줘" | 경기 전환 | 리플레이 재로드 | find_session → loadSession |
| 8 | "강조 그만" | 마커 해제 | 마커 사라짐 | clearHighlight *(추가 시)* |

> 흐름 의도: **용어 → 선수 → 상황 → 이유 → 제어 → 장면 → 경기전환** 순으로,
> "몰라도 물어보면 알려주고 화면이 반응한다"를 한 번에 체감시킨다.

---

## 말투 가이드 (이미 구현 · 데모 시 확인용)
- 2~3문장, 60자 안팎, 존댓말, 초등학생 눈높이
- 목록 나열 금지(음성이라), 더 필요하면 "더 설명해드릴까요?"로 멈춤

**좋은 예 / 피할 예**
- ✅ "해밀턴은 타이어가 닳아서 피트인했어요. 새 타이어로 바꾸면 다시 빨라져요."
- ❌ (장황) "해밀턴은… 1스틴트 소프트, 2스틴트 하드, 3스틴트 미디엄으로… (긴 목록)"

---

## 백업·주의 (데모 사고 방지)
- **마이크 안 되면** → 텍스트 테스터로 같은 발화 입력 (동작 동일)
- **STT 숫자 오인식**("일번"→"일본") → 안 되면 **선수 이름**으로 말하거나 텍스트 사용
- **모나코 등 트랙 에셋 없는 경기** → 차만 뜨고 코스 안 보임 → 데모는 **스즈카**로
- **경기전환은 데이터 서버 필요** → :8000 꺼지면 실패
- **첫 응답 지연** → 워밍업 미리 돌려두기(부팅 시 모델 로드)

---

## 데모 성공 기준 (수용 기준)
① 선수 질문 → 정보+강조 ② 상황 질문 → 순위 ③ "천천히" → 속도
④ "첫 피트스톱" → 점프 ⑤ "왜?" → 근거 설명 — **5개가 끊김 없이** 되면 데모 통과.
